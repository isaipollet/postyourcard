# De Binnenstad pitch · voorjaar 2026

6-pagina A4-landscape sales deck om PostYourCard naar De Binnenstad te brengen voor festivals.

## Bestanden

- `pitch.html` — editable bron, refereert losse images. Gebruik dit om de deck te updaten.
- `pitch-share.html` — standalone (3.1 MB) met fonts + images base64-embed. Werkt offline, deelbaar via Notes/Mail/iMessage.
- `images/` — festival-crowd.jpg (slide 3) en festival-stage.jpg (slide 4)

## Slides

1. Cover — PostYourCard × De Binnenstad
2. Wat het is — 3 SVG-stappen (scan, personaliseer, wereldwijd)
3. Festival-moment — twin postcard mockup (front + back)
4. Branding canvas — achterkant van de kaart met festival-logo
5. Twee modellen — €7.99 visitor-paid (20% revshare) of €4-5 sponsor-paid bulk
6. Pilot voorstel — één festival zomer 2026

## Updaten

1. Open `pitch.html` in Chrome
2. Edit HTML/CSS direct
3. Voor delen: regenereer de standalone met `marketing/_scripts/embed.py` (TODO) of:
   - Open in Chrome → ⌘P → Bewaar als PDF (A4 liggend, marges geen, achtergrondafbeeldingen aan)

## Pricing-placeholders

- 20% revshare in visitor-paid model — overgenomen uit hotel-commissiemodel
- €4-5/kaart sponsor-paid bulk vanaf 5.000 stuks — schatting, herzie vóór elk gesprek
